## About

I develop websites, systems, and digital interfaces by bridging the gap between engineering and design—crafting products that work reliably and scale cleanly. Based in Campinas, Brazil.

- **Current Role:** Design Engineer at [Areco](https://areco.com.br/)
- **Education:** 
  - Degree in Systems Analysis and Development (Graduated)
  - Post-graduate in UX and Beyond at PUCRS (In progress)
  - Oracle Next Education Alumni
- **Specializations:** Design Systems, Frontend Architecture, UI/UX Design, and AI Integration
- **Approach:** Root-cause diagnosis before coding, rapid functional prototyping, and production-ready interfaces built with clean architecture.
